## ▶️ Getting Started

Each day's project is independent. To run a specific day's project, do the following (example: day3):

1. Open a terminal and change into the day folder:

```bash
cd day3
```

2. Install dependencies:

```bash
npm install
```

3. Run the development server:

```bash
npm run dev
```

Repeat the same steps for day5/ and day7/ if you want to run those examples.

If you prefer a single root workspace, I can add a root package.json with workspaces to install all day folders together — tell me if you'd like that.
